# Laboratorio 2 — Primer workflow de triaje en n8n

En este laboratorio automatizarás con n8n la primera parte del proceso analizado en M01.

El workflow recibirá una alerta de prueba, comprobará que contiene la información mínima necesaria, aplicará las reglas P1–P4 y producirá un resultado estructurado.

## Archivos

- `ENUNCIADO.md`: instrucciones del laboratorio.
- `materiales/casos_prueba.json`: casos para validar las distintas rutas.
- `materiales/resultados_esperados.md`: resultados de referencia para comprobar las pruebas.

En este módulo todavía no utilizaremos Webhooks, APIs externas ni Dify. Esas capacidades se añadirán progresivamente en los siguientes módulos.
