# Automatización y agentes sin código — Laboratorios V2

Repositorio de trabajo para la siguiente edición del curso **Automatización y agentes sin código para perfiles técnicos**.

> Estado: diseño en progreso. Este repositorio no sustituye al repositorio de la edición anterior hasta que la V2 esté validada.

## Principios de diseño

- Un único caso de uso de M01 a M09.
- Filosofía **learn by doing**.
- Cada módulo amplía una solución que ya funciona.
- Los conceptos se introducen cuando la solución los necesita.
- El foco principal es experimentar con automatización real, IA, RAG y agentes.
- Validación, contratos, errores, seguridad y Human-in-the-Loop se mantienen, pero como soporte de la solución, no como protagonistas.
- M06–M08 concentran la evolución agentic.
- M09 es dirigido, igual para todos y debe poder completarse en menos de 2 horas.

## Caso conductor

**Telvora Incident Investigation & Response Advisor**

La solución evoluciona progresivamente hasta recibir una alerta, enriquecerla mediante APIs, calcular prioridad, utilizar IA y RAG, investigar mediante un Agent con tools MCP, generar una recomendación y aplicar una política de acción/revisión humana.
