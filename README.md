# Automatización y agentes sin código — Laboratorios

Repositorio de laboratorios del curso **Automatización y agentes sin código para perfiles técnicos**.

Durante el curso construiremos de forma progresiva una misma solución: **Telvora Incident Investigation & Response Advisor**.

La solución evolucionará módulo a módulo desde una automatización básica en n8n hasta una solución integrada con APIs, IA generativa, RAG, agentes con herramientas y revisión humana.

## Enfoque

Los laboratorios siguen una filosofía **learn by doing**:

- cada módulo amplía lo construido anteriormente;
- se trabaja con un único escenario técnico común;
- los conceptos se introducen cuando son necesarios para evolucionar la solución;
- todos los datos son ficticios y se utilizan exclusivamente con fines formativos.

## Herramientas principales

- **n8n** para workflows, eventos, decisiones e integraciones;
- **Dify** para IA generativa, RAG y agentes;
- APIs y servicios de laboratorio proporcionados durante el curso.

## Estructura

Cada módulo contiene un laboratorio con:

- `README.md`: resumen y propósito del laboratorio;
- `ENUNCIADO.md`: instrucciones para realizarlo;
- `materiales/`: archivos necesarios para las pruebas.

No utilices credenciales reales, información productiva ni datos corporativos sensibles en los ejercicios.
