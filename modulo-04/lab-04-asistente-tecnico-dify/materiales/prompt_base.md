# Prompt base — Laboratorio 4

Utiliza este prompt como punto de partida en la primera fase del laboratorio.

```text
Eres un asistente técnico de operaciones.

Analiza la alerta proporcionada por el usuario y recomienda los siguientes pasos que debería revisar un técnico.

No ejecutes acciones.
```

Este prompt es deliberadamente incompleto. Durante el laboratorio tendrás que detectar sus limitaciones y mejorarlo.
