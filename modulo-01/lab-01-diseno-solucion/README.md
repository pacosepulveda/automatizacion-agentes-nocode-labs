# Laboratorio 1 — Diseñando la automatización

En este laboratorio analizarás el proceso manual de triaje e investigación inicial de alertas técnicas de Telvora.

El objetivo es identificar qué partes del trabajo pueden automatizarse mediante un workflow, cuáles requieren interpretación mediante IA, cuándo tiene sentido utilizar un agente y qué decisiones deben seguir bajo control humano.

Este laboratorio prepara la solución que iremos construyendo durante todo el curso.

## Archivos

- `ENUNCIADO.md`: instrucciones del laboratorio.
- `materiales/alertas_iniciales.json`: alertas ficticias de partida.
- `materiales/catalogo_activos.csv`: información de los activos.
- `materiales/mapa_solucion.md`: plantilla de trabajo.

Todos los datos son ficticios. No utilices información productiva ni sensible.
